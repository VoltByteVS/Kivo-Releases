# Kivo Releases

Official downloads and update metadata for Kivo Password Manager.

This repository is for distribution only: verified Windows installers, Android APKs, optional browser-extension packages, checksums, and release notes. Kivo's source code is maintained separately in a private repository.

**No production-ready public release is available yet.** Development and testing builds must not be used to store important real-world passwords.

The manually installed browser extension is optional and requires the Windows app. Keep its extracted folder after loading it as an unpacked extension.

Releases will appear under this repository's **Releases** section after build, signing, and testing gates are met.
