# Kivo release notes

## 0.6.6 Beta 1 — testing in progress (not publicly downloadable)

- Added a version-check endpoint and update notifications for Windows and Android.
- Added **Check for updates** in Settings.
- Newer published versions can display release notes with **Get update** and **Later** actions.
- Added a one-time **What's New** dialog after updating and unlocking the vault.
- App update checks currently open the download URL; they do not silently install updates.

**Release status:** The backend endpoint is deployed, and local Windows/Android test packages have been built. Signing and full device-upgrade testing are not complete. No public installer or APK is published, and the update feed has no announced release yet.

Public downloads will be added through GitHub Releases only after signing, integrity verification, and installation testing. Source remains in a private GitHub repository.
